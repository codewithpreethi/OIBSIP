# Number Guessing Game

## Oasis Infobyte — Java Development — Task 2

### Objective

A Java console-based number guessing game where the computer generates a random number and the user receives higher/lower hints until the number is guessed or the maximum number of attempts is reached.

### Technology

- Java
- Random
- Scanner

### Features

- Random number from 1 to 100
- Maximum of 7 attempts per round
- "Too High!" and "Too Low!" hints
- "Correct!" message when the number is guessed
- Attempt counter
- "You Lost!" message after maximum attempts
- Displays the correct number when the user loses
- Play Again option
- Round and total-attempt summary
- Input validation

### How to Run

Compile:

```bash
javac NumberGuessingGame.java
